Connecter votre Google Sheet

Vos données seront stockées dans votre propre Google Sheets, accessible depuis n'importe quel appareil.

1
Ouvrir Google Apps Script
Rendez-vous sur script.google.com et créez un nouveau projet.
2
Coller le code backend
Remplacez tout le contenu de Code.gs par le code fourni dans le fichier Code.gs joint à l'application.
3
Déployer en tant que Web App
Cliquez sur Déployer → Nouvelle application Web. Choisissez Exécuter en tant que : Moi et Accès : Tout le monde.
4
Coller l'URL ci-dessous
Copiez l'URL générée par Google (commence par https://script.google.com/macros/s/...) et collez-la ici.

🔒 Votre URL est sauvegardée uniquement sur cet appareil. Vos données restent dans votre Google Drive.
